# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes a pizza restaurant's sales data using SQL to extract meaningful business insights. By querying transactional data, the project identifies customer purchasing patterns, sales trends, product performance, and revenue metrics to support data-driven decision-making.

The analysis demonstrates how SQL can be used to solve real-world business problems through data extraction, aggregation, filtering, joins, and analytical functions.

---

## 🎯 Objectives

- Calculate total revenue generated from pizza sales
- Determine the total number of orders placed
- Calculate the total quantity of pizzas sold
- Find the average order value
- Identify the highest-priced pizza
- Determine the most commonly ordered pizza size
- Identify the top-selling and least-selling pizzas
- Analyze category-wise and size-wise sales
- Find peak order hours and busiest days
- Calculate revenue contribution by pizza type
- Generate actionable business insights
